# 样式组织约定

- `app.css` 只导入主题、基础规则和确实跨组件复用的样式。
- 页面或组件专属样式与对应的 Vue 文件放在同一目录，通过 `<style src>` 引入。
- 响应式规则留在所属模块的样式文件中，不集中堆放。
- 只有多个功能共同使用的规则才能进入 `shared/`。
- 覆盖 Naive UI 内部结构时必须由所属组件负责，避免新增无归属的全局覆盖。
- 桌面端 Modal 默认不使用进入、退出或遮罩过渡。Naive UI 的缩放动画会在 WebView 创建弹窗、排版文本和绘制阴影时放大掉帧感；相关覆盖由 `WorkspaceDialogs.css` 统一维护，未经真实 Tauri 窗口回归不要重新启用。
- 带 `loading` 的自适应按钮必须保持原有宽度。全局规则在加载时让原文字继续占位，并把 Spinner 覆盖到按钮中央；不要通过插入加载图标或替换为不同长度文案造成相邻控件移动。
- 弹窗中的异步内容应预留稳定的内容高度，避免 Spinner、空状态和长文本互换时改变弹窗尺寸。Drawer、Popover 和 Dropdown 属于不同交互形态，需要单独评估，不能直接沿用 Modal 规则。
- 提交前运行 `pnpm check`。
