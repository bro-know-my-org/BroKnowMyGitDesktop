# 样式组织约定

- `app.css` 只导入主题、基础规则和确实跨组件复用的样式。
- 页面或组件专属样式与对应的 Vue 文件放在同一目录，通过 `<style src>` 引入。
- 响应式规则留在所属模块的样式文件中，不集中堆放。
- 只有多个功能共同使用的规则才能进入 `shared/`。
- 界面与代码字体、字号、字重、编程连字和 Diff 行高统一由 `tokens.css` 的 `--app-*` 变量提供，并由 `src/shared/fonts/index.ts` 更新。组件不得写死平台字体或直接读取字体设置；代码、SHA、分支名和 Diff 必须使用代码字体 token。
- Diff 增删背景属于行容器而非内部语法 token；行号栏、内容与背景必须共享计算后的行高，避免字体缩放时相邻红绿行重叠。
- 覆盖 Naive UI 内部结构时必须由所属组件负责，避免新增无归属的全局覆盖。
- 桌面端 Modal 默认不使用进入、退出或遮罩过渡。Naive UI 的缩放动画会在 WebView 创建弹窗、排版文本和绘制阴影时放大掉帧感；相关覆盖由 `WorkspaceDialogs.css` 统一维护，未经真实 Tauri 窗口回归不要重新启用。
- 带 `loading` 的自适应按钮必须保持原有宽度。全局规则在加载时让原文字继续占位，并把 Spinner 覆盖到按钮中央；应使用 Naive UI 提供的 `.n-button--loading` 状态类，不要用 `:has()` 检测会由 Transition 动态增删的 Spinner 内部节点，否则 WebKitGTK 可能在节点移除后保留过期的匹配结果，造成按钮文字长期不可见。不要通过插入加载图标或替换为不同长度文案造成相邻控件移动。
- 在桌面 WebView 中不要用 `:has()` 表达依赖动态子节点挂载、卸载的组件状态。优先使用组件公开的状态类、ARIA 属性或由 Vue 显式绑定的 class；静态结构选择不受此限制。新增 `:has()` 前必须确认它不依赖 Transition、Teleport 或条件渲染节点，并在真实 Tauri 窗口验证状态往返后样式会恢复。
- 弹窗中的异步内容应预留稳定的内容高度，避免 Spinner、空状态和长文本互换时改变弹窗尺寸。Drawer、Popover 和 Dropdown 属于不同交互形态，需要单独评估，不能直接沿用 Modal 规则。
- 提交前运行 `pnpm check`。
